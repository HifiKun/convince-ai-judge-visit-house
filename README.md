A single-image letter inviting the AI judge to visit my house: warm paper, a hand-drawn house with a sleeping cat, and a short, funny, persuasive invitation. The program draws the letter with Pillow and writes it to `/output/entry.png` (1024×1024 PNG, under 1 MiB).

## Run it

```sh
python3 main.py
```
